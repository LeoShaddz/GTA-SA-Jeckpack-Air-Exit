# GTA San Andreas  Jeckpack Air Exit Mod

This mod allows you to exit the jetpack while in mid-air, just like in the mobile version. However, to prevent accidental exits when pressing the button, you must hold down the key to exit the jetpack—and this only works while airborne. The mod also supports game controllers.

The mod is customizable; you can set the number of seconds you need to hold the key in the .ini file.
